Tutorial Membuat GUI Music Roblox dari Awal Sampai Jadi

18 September 2026 · KINGSULA.

🎵

Pada tutorial ini kita akan membuat GUI music sederhana untuk game Roblox. Hasil akhirnya memiliki nama lagu, tombol Play atau Pause, Stop, Next, serta tombol untuk menaikkan dan menurunkan volume. Tutorial ini cocok untuk pemula karena setiap bagian dibuat dan diuji satu per satu.

Hasil Akhir yang Akan Dibuat

Sistem ini memakai beberapa object Sound yang berada di SoundService. Saat pemain menekan tombol, LocalScript akan menjalankan fungsi yang sesuai. Music yang diputar hanya terdengar oleh pemain tersebut, sehingga setiap pemain bisa mengatur musiknya sendiri.

1. Siapkan GUI di Roblox Studio

Buka Roblox Studio dan ikuti struktur object berikut. Nama object harus sama agar script dapat menemukannya: 

StarterGui
└── MusicGui (ScreenGui)
    ├── MusicFrame (Frame)
    │   ├── SongName (TextLabel)
    │   ├── PlayButton (TextButton)
    │   ├── StopButton (TextButton)
    │   ├── NextButton (TextButton)
    │   ├── VolumeDown (TextButton)
    │   ├── VolumeUp (TextButton)
    │   └── VolumeText (TextLabel)
    └── MusicScript (LocalScript)

Cara membuatnya: klik kanan StarterGui, pilih ScreenGui, lalu beri nama MusicGui. Di dalamnya buat satu Frame bernama MusicFrame. Masukkan semua TextLabel dan TextButton ke dalam Frame. Terakhir, masukkan LocalScript ke dalam MusicGui, bukan ke dalam Frame.

Atur tulisan tombol menjadi Play, Stop, Next, -, dan +. Kamu bebas mengatur warna, ukuran, posisi, dan desainnya.

2. Masukkan Music ke SoundService

Di Explorer, klik kanan SoundService lalu buat tiga object Sound. Beri nama persis seperti contoh berikut: 

SoundService
├── Music1 (Sound)
├── Music2 (Sound)
└── Music3 (Sound)

Pilih setiap Sound, lalu isi property SoundId dengan audio Roblox yang boleh digunakan. Formatnya seperti rbxassetid://1234567890. Jangan menyalin ID audio secara sembarangan; pastikan audio tersebut tersedia dan sesuai aturan Roblox.

Atur property Looped menjadi false karena script akan berpindah ke lagu berikutnya setelah lagu selesai. Atur Volume awal menjadi 0.5.

3. Hubungkan Tombol dengan Script

Buka MusicScript, hapus isi awalnya, lalu masukkan kode lengkap berikut: 

local soundService = game:GetService("SoundService")
local musicGui = script.Parent
local musicFrame = musicGui:WaitForChild("MusicFrame")

local songName = musicFrame:WaitForChild("SongName")
local playButton = musicFrame:WaitForChild("PlayButton")
local stopButton = musicFrame:WaitForChild("StopButton")
local nextButton = musicFrame:WaitForChild("NextButton")
local volumeDown = musicFrame:WaitForChild("VolumeDown")
local volumeUp = musicFrame:WaitForChild("VolumeUp")
local volumeText = musicFrame:WaitForChild("VolumeText")

local songs = {
    soundService:WaitForChild("Music1"),
    soundService:WaitForChild("Music2"),
    soundService:WaitForChild("Music3")
}

local currentSong = 1
local volume = 0.5

local function updateVolumeText()
    volumeText.Text = "Volume: " .. math.round(volume * 100) .. "%"
end

local function stopAllSongs()
    for _, song in ipairs(songs) do
        song:Stop()
    end
end

local function playSong(songIndex)
    stopAllSongs()
    currentSong = songIndex
    songs[currentSong].Volume = volume
    songs[currentSong]:Play()
    songName.Text = "Playing: " .. songs[currentSong].Name
    playButton.Text = "Pause"
end

playButton.MouseButton1Click:Connect(function()
    local currentSound = songs[currentSong]

    if currentSound.IsPlaying then
        currentSound:Pause()
        playButton.Text = "Play"
    else
        currentSound:Resume()
        playButton.Text = "Pause"
    end
end)

stopButton.MouseButton1Click:Connect(function()
    stopAllSongs()
    songName.Text = "Music berhenti"
    playButton.Text = "Play"
end)

nextButton.MouseButton1Click:Connect(function()
    currentSong = currentSong + 1

    if currentSong > #songs then
        currentSong = 1
    end

    playSong(currentSong)
end)

volumeDown.MouseButton1Click:Connect(function()
    volume = math.max(0, volume - 0.1)

    for _, song in ipairs(songs) do
        song.Volume = volume
    end

    updateVolumeText()
end)

volumeUp.MouseButton1Click:Connect(function()
    volume = math.min(1, volume + 0.1)

    for _, song in ipairs(songs) do
        song.Volume = volume
    end

    updateVolumeText()
end)

for _, song in ipairs(songs) do
    song.Ended:Connect(function()
        if song == songs[currentSong] then
            currentSong = currentSong + 1

            if currentSong > #songs then
                currentSong = 1
            end

            playSong(currentSong)
        end
    end)
end

updateVolumeText()
songName.Text = "Tekan Play untuk mulai"
playButton.Text = "Play"

4. Penjelasan Bagian Penting

Baris WaitForChild() digunakan agar script menunggu object tersedia sebelum dipakai. Ini lebih aman daripada langsung menulis nama object, terutama saat game baru dimulai.

Tabel songs menyimpan semua music yang ingin diputar. Variabel currentSong menyimpan posisi lagu yang sedang dipilih, sedangkan volume menyimpan volume saat ini dalam angka antara 0 sampai 1.

Fungsi playSong() menghentikan semua lagu, memilih lagu baru, menerapkan volume, lalu memutarnya. Tombol Next cukup menaikkan nomor currentSong. Jika sudah melewati lagu terakhir, nomor dikembalikan ke lagu pertama.

5. Uji GUI Music

Klik tombol Play di Roblox Studio. Coba tekan Pause, Play lagi, Stop, dan Next. Tekan tombol + atau - untuk memastikan volume berubah. Jika lagu pertama selesai, script seharusnya otomatis memutar lagu berikutnya.

Jika tampilan terlalu kecil, pilih MusicFrame dan atur property Size serta Position. Untuk membuat GUI tetap nyaman di HP, gunakan ukuran berbasis skala dan aktifkan TextScaled pada label atau tombol seperlunya.

6. Error yang Sering Terjadi

  • Infinite yield possible: periksa nama object dan lokasi setiap tombol.
  • Music tidak terdengar: periksa SoundId, izin audio, Volume, dan apakah audio masih tersedia.
  • Tombol tidak merespons: pastikan yang digunakan adalah LocalScript, bukan Script biasa.
  • Next error: pastikan semua nama Sound sama dengan nama dalam tabel songs.
  • GUI tidak muncul: pastikan MusicGui berada di StarterGui dan property Enabled aktif.

Kesimpulan

GUI music Roblox dibuat dari tiga bagian utama: tampilan GUI, kumpulan Sound, dan LocalScript sebagai pengatur. Setelah sistem dasar ini berhasil, kamu bisa mengembangkannya dengan daftar lagu, progress bar, tombol mute, animasi frame, atau sistem playlist yang lebih lengkap.

Kerjakan dan uji satu bagian setiap kali. Dengan begitu, jika muncul error, kamu lebih mudah mengetahui apakah masalahnya ada pada nama object, SoundId, atau kode tombolnya.
