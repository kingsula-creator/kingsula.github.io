Membuat Admin Panel Roblox untuk Give Title dan Give Role

18 September 2026 · KINGSULA.

🛡️

Pada tutorial ini kita akan membuat admin panel Roblox yang bisa digunakan untuk memberikan title dan role kepada pemain. Admin dapat mengisi UserId atau username target, menulis title, memilih role, lalu menekan tombol Give Title atau Give Role.

Fitur Admin Panel

  • Panel hanya muncul untuk UserId yang masuk whitelist admin.
  • Target bisa dicari memakai UserId atau username.
  • Admin dapat memberikan title custom seperti Content Creator atau Builder.
  • Role dibatasi ke Player, VIP, Moderator, dan Admin.
  • Title dan role tampil di atas kepala pemain.
  • Perintah diproses server sehingga pemain biasa tidak bisa mengirim give title sendiri.

1. Siapkan Dua Script

Tutorial ini memakai dua script. Script server menangani keamanan, whitelist, pencarian pemain, dan pemberian title atau role. LocalScript membuat tampilan panel dan mengirim permintaan ke server.

Download file yang sudah disiapkan di bawah ini:

Download Server Script → Download Client Script →

2. Pasang Server Script

Di Roblox Studio, buka ServerScriptService. Buat object Script baru, lalu salin isi AdminPanelServer.lua ke dalamnya.

Di bagian atas script ada whitelist admin: 

local ADMIN_USER_IDS = {
    [123456789] = true,
}

Ganti angka 123456789 dengan UserId akunmu. UserId lebih aman daripada username karena username bisa berubah. Untuk menambahkan admin lain, tambahkan baris baru: 

local ADMIN_USER_IDS = {
    [987654321] = true,
    [123456789] = true,
}

3. Pasang Client Script

Buka StarterPlayer > StarterPlayerScripts. Buat object LocalScript baru, lalu salin isi AdminPanelClient.lua ke dalamnya.

GUI akan dibuat otomatis saat admin masuk ke game. Kamu tidak perlu membuat Frame, TextBox, atau tombol secara manual. Panel berisi input target, input title, input role, tombol Give Title, dan tombol Give Role.

4. Cara Menggunakan Panel

  1. Jalankan game menggunakan akun yang UserId-nya sudah masuk whitelist.
  2. Di kolom target, tulis UserId atau username pemain yang sedang online.
  3. Di kolom title, tulis title yang ingin diberikan, misalnya Content Creator.
  4. Tekan GIVE TITLE.
  5. Untuk role, isi salah satu pilihan: Player, VIP, Moderator, atau Admin.
  6. Tekan GIVE ROLE.

Contoh pengisian: 

Target: Tulis UserId atau username di sini
Title: Content Creator
Role: Moderator

Setelah berhasil, title dan role akan terlihat di atas kepala target. Pesan status di panel juga akan memberi tahu apakah proses berhasil atau gagal.

5. Kenapa Keamanan Diproses di Server?

LocalScript berada di perangkat pemain, sehingga jangan menaruh daftar admin hanya di LocalScript. Pemain yang tidak bertanggung jawab bisa mencoba mengubah LocalScript miliknya sendiri. Karena itu server memeriksa UserId pengirim sebelum menerima perintah Give Title atau Give Role. 

if not isAdmin(player) then
    return false, "Kamu tidak memiliki izin admin."
end

Pemeriksaan ini membuat pemain biasa tidak bisa memakai RemoteFunction untuk memberikan role kepada dirinya sendiri.

6. Error yang Sering Terjadi

  • Panel tidak muncul: pastikan Client Script berupa LocalScript dan berada di StarterPlayerScripts.
  • Tidak punya izin admin: periksa UserId akunmu di tabel ADMIN_USER_IDS.
  • Username tidak ditemukan: target harus sedang online dan nama harus benar.
  • Role tidak diterima: gunakan Player, VIP, Moderator, atau Admin sesuai daftar script.
  • Title tidak terlihat: respawn pemain atau pastikan karakter memiliki object Head.

Kesimpulan

Admin panel ini memberi dasar yang aman untuk sistem staff Roblox. Kamu bisa mengembangkannya dengan tombol hapus title, penyimpanan DataStore, daftar pemain online, role dengan warna berbeda, atau log aktivitas admin. Sebelum dipublish, uji menggunakan beberapa akun agar permission tidak salah.
