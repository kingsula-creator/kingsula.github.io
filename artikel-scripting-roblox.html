Coding Roblox untuk Pemula: Mengenal Luau dan Script Pertama

18 September 2026 · KINGSULA.

💻

Coding di Roblox adalah proses memberikan instruksi kepada game agar bisa melakukan sesuatu. Contohnya, pintu terbuka ketika disentuh, pemain mendapatkan koin, atau tombol menampilkan sebuah menu. Di Roblox Studio, kita menggunakan bahasa pemrograman bernama Luau.

1. Apa Itu Luau?

Luau adalah bahasa pemrograman yang dikembangkan dari Lua dan digunakan oleh Roblox. Luau memiliki sintaks yang cukup mudah dibaca, sehingga cocok untuk belajar logika pemrograman sambil membuat game.

2. Script, LocalScript, dan ModuleScript

Ada tiga jenis script yang sering ditemui. Script biasanya dipakai untuk logika di server, misalnya memberi hadiah kepada pemain. LocalScript berjalan di perangkat pemain dan cocok untuk input atau tampilan antarmuka. ModuleScript dipakai untuk menyimpan kode yang ingin digunakan kembali oleh script lain.

Untuk latihan pertama, buat object Script di dalam ServerScriptService. Lokasi ini membantu script server berjalan ketika game dimulai.

3. Script Pertama: Menampilkan Pesan

Hapus isi script, lalu tulis kode berikut: 

print("Halo, Roblox!")

Klik tombol Play, lalu buka panel Output di Roblox Studio. Jika berhasil, kamu akan melihat tulisan “Halo, Roblox!”. Fungsi print() berguna untuk memeriksa apakah bagian kode tertentu sudah berjalan.

4. Membuat Variabel

Variabel adalah tempat untuk menyimpan data. Misalnya, kita ingin menyimpan jumlah koin pemain: 

local coins = 10
print(coins)

Kata local membuat variabel yang digunakan di dalam bagian script tersebut. Nama coins adalah nama variabelnya, sedangkan angka 10 adalah nilainya.

5. Membuat Part Berubah Warna

Sekarang kita coba berinteraksi dengan object di map. Buat sebuah Part di Workspace, lalu masukkan Script ke dalam Part tersebut dan gunakan kode ini: 

local part = script.Parent

part.BrickColor = BrickColor.new("Bright blue")

script.Parent berarti object yang menjadi tempat script berada. Karena script dimasukkan ke dalam Part, variabel part akan merujuk ke Part tersebut. Saat game berjalan, warnanya berubah menjadi biru.

6. Membuat Event Saat Part Disentuh

Event adalah kejadian yang bisa ditanggapi oleh script. Contoh berikut mengubah warna Part ketika disentuh: 

local part = script.Parent

part.Touched:Connect(function()
    part.BrickColor = BrickColor.new("Bright red")
end)

Touched aktif ketika ada object yang menyentuh Part. Bagian di antara function() dan end adalah perintah yang dijalankan setelah event terjadi.

7. Kesalahan yang Sering Terjadi

Jika script tidak bekerja, jangan langsung menghapus semuanya. Periksa beberapa hal berikut:

  • Pastikan jenis script sesuai dengan lokasi object.
  • Periksa ejaan nama object dan variabel.
  • Buka panel Output untuk membaca pesan error berwarna merah.
  • Pastikan setiap tanda kurung dan kata end sudah lengkap.
  • Uji satu perubahan kecil setiap kali agar mudah menemukan sumber masalah.

Kesimpulan

Belajar coding Roblox tidak harus dimulai dari sistem yang besar. Pahami dulu variabel, object, event, dan cara membaca error. Setelah itu, gabungkan konsep-konsep kecil tersebut menjadi fitur seperti koin, pintu, checkpoint, shop, atau sistem game lainnya.

Yang paling penting adalah sering mencoba. Script yang error bukan berarti kamu gagal, tetapi memberi petunjuk tentang bagian mana yang perlu dipahami lagi.
