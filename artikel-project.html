Project yang Sedang Dibuat

14 September 2026 · KINGSULA.

🚀

Membuat sebuah project dari nol merupakan proses yang menarik. Setiap bagian membutuhkan perencanaan, percobaan dan tentunya banyak proses debugging.

HANGOUT KIT

Salah satu project yang sedang dikembangkan adalah sebuah Hangout Kit untuk Roblox.

Project ini dibuat dengan berbagai sistem seperti music, emote, inventory, server list, shop, admin system dan berbagai fitur lainnya.

SUMMIT KIT

Selain Hangout Kit, terdapat juga project Summit Kit yang memiliki sistem checkpoint, summit counter, basecamp dan leaderboard.

Membangun dari Nol

Setiap project dibuat secara bertahap. Mulai dari struktur folder, sistem dasar, kemudian fitur-fitur tambahan.

Tujuannya bukan hanya membuat project yang bisa digunakan, tetapi juga memahami bagaimana setiap sistem bekerja.

Terus Berkembang

Project akan terus dikembangkan dan diperbaiki. Setiap update membawa fitur baru dan pengalaman baru dalam proses pembuatannya.
